# KVMB SoundFont

**KVMB** is a compact General MIDI SoundFont based on `gm.sf2`.

## Overview

KVMB is a lightweight SoundFont project focused on providing a compact instrument bank for MIDI playback and experimentation.

- **Project:** KVMB
- **Format:** SoundFont 2 (`.sf2`)
- **Base SoundFont:** `gm.sf2`
- **File size:** Approximately 3 MB
- **Metadata editor:** Polyphone
- **Category:** General MIDI SoundFont

## Features

- Compact file size.
- General MIDI-oriented instrument bank.
- Suitable for MIDI playback and sequencing.
- Designed for lightweight use.
- Includes customized SoundFont metadata.

## Development

KVMB was created by modifying the original `gm.sf2` SoundFont.

The project metadata, including the product name, comments, filename, and corporation information, was customized using Polyphone.

## Compatibility

KVMB uses the SoundFont 2 format and can be loaded by applications and synthesizers that support SF2 files.
